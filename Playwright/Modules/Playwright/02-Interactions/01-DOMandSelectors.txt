To inspect elements of a page, press F12 and go to the Elements tab.
Element that is being investigated will be highlighted on the page.

DOM - document object model
It is roughly shaped like a tree with branches (nodes) but turned upside-down

<h3 class="ud-heading-lg">Wyróżnione pytania w tym kursie</h3>
h3 is a tag. There is an opening tag and a closing tag with a /.
tags are have attributes - here it is class.
Attributes have values, here is is ud-heading-lg
Finally, there is text that is visible on the page: Wyróżnione pytania w tym kursie
Sample text visible in the text fields might not placed in html as the one above, it might be an attribute.

special attributes:
id - it is unique on each page and makes a basis for a good selector.
class - can have multive values in one attribute separated by spaces and they may be dynamic.
