To inspect elements of a page, press F12 and go to the Elements tab.
Element that is being investigated will be highlighted on the page.

DOM - document object model
It is roughly shaped like a tree with branches (nodes) but turned upside-down

<h3 class="ud-heading-lg">Wyróżnione pytania w tym kursie</h3>
h3 is a tag. There is an opening tag and a closing tag with a /.
tags are have attributes - here it is class.
Attributes have values, here is is ud-heading-lg
Finally, there is text that is visible on the page: Wyróżnione pytania w tym kursie
Sample text visible in the text fields might not placed in html as the one above, it might be an attribute.

special attributes:
id - it is unique on each page and makes a basis for a good selector.
class - can have multive values in one attribute separated by spaces and they may be dynamic.

Locating elements:
by tag 
page.locator('input');

by id (#) (id="inputEmail"):
page.locator('#inputEmail');

by class (.) (class="shape-rectangle"):
page.locator('.shape-rectangle');

by any other attribute and its value:
page.locator([placeholder='Email']);

by several selectors
page.locator('input[placeholder='Email'].shape-rectangle');

xpath support - xpath is not recommended for playwright, use user-visible locators.
page.locator(//*[@id='inputEmail']);

by text (partial match)
page.locator(':text("Text to find")');

by text (exact match)
page.locator(':text-is("Exact text match")');

Locators can be stored in variables for better management and reuse.
The following line can be simplified if we are going to use some of its elements later:
await page.locator('locator', hasText: 'text').locator('locator').cick();

const elementLocator = page.locator('locator', hasText: 'text'); //locator is not a promise, so await is not needed here.
await elementLocator.locator('locator').cick();

We go a step further and put a variable into another variable if needed:
const elementLocator = page.locator('locator', hasText: 'text');
const anotherLocator = elementLocator.locator('locator');
await anotherLocator.cick();
